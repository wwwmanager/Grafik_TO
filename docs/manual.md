# Руководство пользователя: Генератор графика технического осмотра

Версия: 2026-11-23. Для офисного пользователя без технической подготовки.

---

## 1. Что делает программа

Программа строит **годовой график технических осмотров** самоходной техники.

**На входе:** файл Excel (`.xlsx` или `.xls`) — выгрузка из универсального поиска техники. В файле должны быть колонки «Владелец» и «Дата ТО». Может быть много других колонок (ИНН, адрес, категория, гос. знак, марка и т.д.) — программа найдёт нужные по названиям.

**На выходе:** файл Excel с четырьмя листами:
1. **График ТО** — готовый план выездов (кто, когда, во сколько).
2. **Детализация** — тот же план подробно: адрес, сколько машин, номера знаков, откуда взялась дата.
3. **Исключенные записи** — техника, которой не попало в график, и причина.
4. **Сводка и нагрузка** — загрузка по месяцам и список использованных настроек.

**Что программа НЕ делает:**
- Не отправляет ваш файл в интернет. Вся работа происходит в браузере на вашем компьютере.
- Не требует установки — открывается как обычная веб-страница.
- Не знает пароли, не хранит историю, не ставит куки для слежки.
- Не обращается к внешним картам и геокодерам — адреса анализирует сама по тексту.

---

## 2. Что вам понадобится

1. **Браузер** — Chrome, Edge, Firefox, Safari, Яндекс.Браузер (современные версии).
2. **Файл выгрузки** — Excel (`.xlsx` или `.xls`) из реестра. В первой строке может быть заголовок отчёта (например, «Выгрузка на 23.11.2026»), сами заголовки колонок могут быть ниже (программа найдёт их сама, просканировав первые 30 строк).
3. **Интернет** — только для загрузки производственного календаря РФ (праздники, перенесённые выходные). Если интернета нет или сайт календаря не отвечает — программа использует встроенный календарь на 2025–2027 гг. или просто считает выходными субботу и воскресенье (об этом напишет сообщение).

## 3. Пошаговая инструкция

### Шаг 1. Откройте сайт
Перейдите по адресу: **https://wwwmanager.github.io/Grafik_TO/**

Вы увидите заголовок **«График технического осмотра»** и подзаголовок **«Генератор годового графика ТО по выгрузке из реестра»**.

### Шаг 2. Загрузите файл
В зоне с надписью **«Перетащите файл .xlsx или .xls сюда»** перетащите файл мышью или нажмите кнопку **«Выбрать файл»**.

4. **«Сводка по месяцам»** — таблица: Месяц, Выездов, Машин. Внизу — «Итого» и полный список использованных настроек.

## 4. Почему техника исключена (пояснение причин)

В листе **«Исключенные записи»** в колонке «Причина исключения» могут быть следующие тексты. Все они — на русском, без кодов.

| Причина на экране | Что это значит простыми словами |
|-------------------|--------------------------------|
| **Снято с учёта (заполнена «Дата снятия»)** | В колонке «Дата снятия» стоит дата — техника снята с учёта, осматривать не нужно. |
| **Угон** | В колонке «Угон» стоит значение (да/1/дата и т.п.) — техника в розыске. |
| **Сдан ГРЗ** | В колонке «Сдан ГРЗ» стоит значение — гос. знак сдан, техника не эксплуатируется. |
| **Вывезена за рубеж** | В колонке «Вывезена за рубеж» стоит значение — техника уехала за границу. |
| **Отсутствует или некорректна «Дата ТО»** | Колонка «Дата ТО» пуста или содержит нечитаемую дату. Без даты нельзя посчитать следующий осмотр. |
| **Дата ТО больше выбранной давности ТО** | Последний ТО был раньше 1 января (целевой год − глубина). Например, глубина 3 года, целевой 2027 → граница 01.01.2024. Если Дата ТО 2021 года — исключается. |
| **«Без ТО» без даты ТО, глубина менее 5 лет** | В колонке «Без ТО» стоит `*`, а «Дата ТО» пустая/некорректная. Программа считает, что ТО было более 5 лет назад. Такая техника попадает в график **только если глубина ≥ 5 лет**. При глубине 3 — исключается. |
| **Физлицо с ≤N ед. техники — приём в приёмные дни** | Режим Б: физлицо имеет N или меньше машин (после фильтров). Машины убраны из графика, но в примечании к «Графику ТО» написано, когда и где они проходят ТО. |
| **Физлицо с ≤N ед. техники (вариант А)** | Режим А: физлицо имеет N или меньше машин — полностью исключено из графика, примечания нет. |

**Важно про «Без ТО» = `*`:**
Если в колонке «Без ТО» стоит звёздочка `*` — это значит: **ТО просрочено, техника нуждается в осмотре и ОБЯЗАТЕЛЬНО попадает в график** (это не исключение). Глубина применяется и к такой технике: если есть «Дата ТО» и она старше глубины — исключится; если «Дата ТО» пустая — см. строку выше.

## 5. Как читать листы результата

### Лист 1 — «График ТО»
- **№ п/п** — порядковый номер выезда.
- **Наименование поселения (хозяйства, предприятия)** — берётся из колонки «Владелец» выгрузки. **Без суффикса «(просроченная)».**
- **Дата проведения** — формат ДД.ММ.ГГГГ.
- **Время проведения** — формат «с ЧЧ-ММ до ЧЧ-ММ» (например, «с 09-00 до 10-00»).
- Строки отсортированы по дате и времени.
- Внизу может быть примечание про физлиц (если выбран режим Б).

### Лист 2 — «Детализация»
- **Дата**, **Время (с–по)** — когда и сколько длится выезд.
- **Владелец**, **ИНН**, **Адрес** — из выгрузки.
- **Локация (ключ)** — как программа разобрала адрес: «район / населённый пункт». Если не распознала — «— / —». Это помогает понять, почему выезды сгруппированы так, а не иначе.
- **Кол-во техники** — сколько машин в этом выезде.
- **Длительность, мин** — рассчитано по формуле: ceil(машин / скорость) часов, округлено до 30 минут, минимум 30.
- **Гос. знаки / марки** — пронумерованный список с переносом текста: «1. А123ВС 77 Kamaz; 2. В456НТ 77 GAZ».
- **Единицы и исходные целевые даты** — пронумерованный список с переносом текста: «1. А123ВС 77 — 15.03.2027; 2. В456НТ 77 — 22.05.2027».
- **Источник даты** — откуда взялась целевая дата: «Расчёт («Дата ТО» + 1 год)», ««Дата след. ТО» (выгрузка)», «Просроченная («Дата ТО» + 1 год)», ««Без ТО» (просрочено)», «А4 (+6 мес.)» и т.д.
- **Просроченная** — «да», если техника попала в график как просроченная (распределяется по наименее загруженным месяцам).
- **Перегруз** — «да», если длительность выезда превысила рабочий день (тогда выезд занимает весь день).

### Лист 3 — «Исключенные записи»
Все исходные колонки исключённой техники + **Причина исключения** (см. раздел 4).

### Лист 4 — «Сводка и нагрузка»
- Таблица по месяцам: **Месяц**, **Выездов**, **Машин**.
- Строка «Итого».
- Блок **«Применённые настройки»** — полный список параметров с значениями, которые использовались для этого расчёта. Удобно для проверки и архива.

## 6. Приватность: ваши данные не уходят из браузера

- Файл Excel **никогда не отправляется в интернет и не попадает на какой-либо сервер**. Чтение файла, расчёт дат, анализ адресов, группировка, распределение по дням, создание итогового Excel — всё происходит **на вашем компьютере внутри браузера**.
- Программа не использует сторонние счётчики, аналитику, геокодеры или внешние шрифты.
- **Единственное, что программа может скачать из интернета** — это официальный производственный календарь РФ (праздники и перенесённые выходные) с сайта isdayoff.ru. При этом передаётся только номер года, никаких ваших данных. Если интернета нет или сайт не отвечает, программа использует встроенный календарь на ближайшие годы или просто считает выходными субботу и воскресенье.
- Настройки (порог физлиц, зимние месяцы, их загрузка, периоды отпуска) запоминаются вашим браузером на этом компьютере только для удобства — чтобы при следующем открытии не вводить заново. Это тоже остаётся только у вас.

## 7. Типичные проблемы и что делать

| Симптом | Причина | Что сделать |
|---------|---------|-------------|
| После загрузки файла кнопка «Сформировать график» неактивна | В файле не найдены обязательные колонки «Владелец» и/или «Дата ТО» | Проверьте, что в выгрузке есть эти колонки. Программа ищет их по названию в первых 30 строках. Если заголовки ниже — они всё равно найдутся. |
| Ошибка «Не найдена строка заголовков с колонками «Владелец» и «Дата ТО»» | Лист пустой или структура файла неожиданная | Откройте файл в Excel, убедитесь, что данные на первом листе, заголовки читаемы. Сохраните как `.xlsx` и загрузите снова. |
| Много техники исключено по причине «Отсутствует или некорректна «Дата ТО»» | В выгрузке пустые или нечитаемые даты в колонке «Дата ТО» | Проверьте исходную выгрузку. Форматы дат, которые понимает программа: ДД.ММ.ГГГГ, ГГГГ-ММ-ДД, с разделителями `.`, `-`, `/`, также даты Excel (числа). |
| Физлица с 3 машинами попали в график, а должны были исключиться | Порог физлиц = 3, но Machines считались с единицей, у которой «Без ТО» = `*` или другая причина, из-за которой она не прошла фильтры | Считаются только машины, прошедшие фильтры (шаг 1). Если у физлица 4 машины, но 1 исключена — остаётся 3, и при пороге 3 режим срабатывает. Проверьте лист «Исключенные записи». |
| Просроченная техника ставятся в декабре/январе, а нужно в июне | Зимние месяцы по умолчанию: дек, янв, фев. Загрузка зимних месяцев = 30% | В настройках «Зимние месяцы» снимите галочки с ненужных месяцев, поставьте нужные. Поставьте «Загрузка зимних месяцев, %» = 100, чтобы зима была как обычные месяцы, или = 0, чтобы зимой вообще не ставить. |
| В листе «Детализация» в колонке «Локация (ключ)» везде «— / —» | Адреса в выгрузке в нестандартном формате, программа не нашла маркеры населённых пунктов (г., с., п., д., х., ст-ца, аул, рп и т.д.) и районов («р-н», «район») | Проверьте колонку «Адрес владельца» в выгрузке. Программа теперь понимает: голые названия городов («Москва»), приклеенные маркеры («г.Москва»), маркеры региона («обл.», «край», «АО», «респ.»), а также адреса, разложенные по отдельным колонкам (регион / район / насел. пункт / улица / дом) — через маркеры заголовков. |

Для других лет — только суббота/воскресенье. Если нужно точно — скачайте календарь вручную и укажите приёмные дни/отпуск так, чтобы компенсировать. |
| Файл не скачивается при нажатии «Скачать Excel (.xlsx)» | Браузер блокирует скачивание или нет прав на запись в «Загрузки» | Разрешите скачивание в настройках браузера. Попробуйте другой браузер. |
| В «Графике ТО» владельцы идут в странном порядке | Сортировка по дате и времени выезда, а не по алфавиту | Это нормально. Если нужно по алфавиту — отсортируйте в Excel после скачивания. |

Целевая дата проецируется в целевой год с сохранением месяца и дня (шаг А4 +6 мес.). Такая техника **не просроченная** и попадает в обычный график. |

## 8. Короткий FAQ (частые вопросы)

**В: Нужен ли интернет для работы?**
О: Для загрузки календаря праздников — да. Если интернета нет — программа использует встроенный календарь (2025–2027) или просто считает выходными Сб/Вс. Всё остальное работает офлайн.

**В: Куда девается файл после загрузки?**
О: Никуда. Файл читается в памяти браузера, обрабатывается и тут же забывается. На сервер не уходит. После закрытия вкладки данные исчезают (кроме сохранённых настроек — они остаются в браузере на этом компьютере).

**В: Почему в «Детализации» есть колонка «Источник даты»?**
О: Чтобы вы видели, откуда взялась целевая дата: из выгрузки («Дата след. ТО»), по расчёту («Дата ТО» + 1 год), А4 (+6 мес.), или это просроченная техника, которую программа сама распределила.

**В: Что значит «Перегруз» в детализации?**
О: Выезд получился длиннее рабочего дня (с учётом обеда). Программа ставит его на весь день, флаг «перегруз» — предупреждение инспектору, что времени может не хватить.

**В: Можно ли изменить список зимних месяцев?**
О: Да, в настройках «Зимние месяцы» — кликните по месяцам в сетке 4×3. По умолчанию выбраны январь, февраль, декабрь.

**В: Как указать, что инспектор в отпуске несколько раз?**
О: Поставьте галочку «Отпуск инспектора», появится два поля даты — «Отпуск с» и «Отпуск по». Нажмите **«+ Добавить»**, чтобы добавить ещё один период. Каждый период можно удалить кнопкой **«×»**.

**В: Файл выгрузки содержит лишние колонки — это проблема?**
О: Нет. Программа ищет нужные колонки по нормализованному названию (игнорирует лишние пробелы, переносы строк, ё/е, регистр). Лишние колонки просто игнорируются.

**В: Почему физлица определяются по колонке «Группа владельца»?**
О: В реальной выгрузке есть эта колонка. Значения вроде «Физические лица», «Физ. лицо», «ФЛ» — программа распознаёт по наличию «физ» или отдельного токена «ФЛ». Колонка «Группа» (без «владельца») — это группа техники, её не используем для определения физлица.

**В: Можно ли построить график на текущий год?**
О: Да, в поле «Целевой год» введите текущий год. Но обычно график готовят на следующий год.

**В: Что такое «Группировать малых владельцев по последней дате ТО»?**
О: Если галочка включена (по умолчанию), для физлиц и малых юрлиц (≤ порога единиц техники) целевая дата берётся одна — самая поздняя из их машин. Все машины такого владельца уйдут в один выезд на эту дату. Если выключить — у каждой машины своя дата.

**В: В выгрузке адреса разбиты по колонкам (регион, район, насел. пункт, улица, дом). Программа поймёт?**
О: Да. Программа ищет маркеры в заголовках колонок: «регион», «область», «край», «АО», «респ.»; «район», «р-н»; «насел», «пункт», «город», «село», «посёлок»; «улица», «ул.»; «дом», «д.» — и собирает адрес из этих частей.
