# План слайсов grafik_to (L0). Источники: TZ.md + decisions.md (приоритет) + headers-sample.txt.

Правила для исполнителя (orch1 → дешёвый L3): один слайс = один коммит `feat(GRAFIK-NN): ...`; каждый слайс с
Vitest-тестами на свою логику; после каждого `npm run verify` зелёный; данные в фикстурах только вымышленные;
никаких сетевых запросов, кроме isdayoff.ru в calendarService; без push до GRAFIK-09.

GRAFIK-02 parser.js + фикстуры
- SheetJS (.xlsx/.xls), cellDates; поиск строки заголовков (D6); нормализация заголовков (trim, \s+ → пробел,
  NBSP, переносы, регистр, ё→е); карта колонок по именам; ошибки на отсутствие `Владелец`/`Дата ТО`.
- Даты: Date, Excel serial, строки ДД.ММ.ГГГГ / ГГГГ-ММ-ДД; невалид → null.
- scripts/make-fixture.mjs генерирует tests/fixtures/sample.xlsx по заголовкам headers-sample.txt с титульной
  строкой и ~40 вымышленными строками (юрлица, физлица, А4, снятые, угон, без ТО, старые даты, пустой ИНН, разные районы).
GRAFIK-03 calendarService.js
- isdayoff.ru/api/getdata?year=Y (строка 0/1 по дням) → кэш localStorage; таймаут; fallback public/calendar/{2025,2026,2027}.json
  (сгенерировать скриптом из API один раз и закоммитить; если API недоступен с машины — из официального произв. календаря);
  неизвестный год → Сб/Вс + флаг warning. isWorkingDay(date, settings) с приёмными днями и отпуском.
GRAFIK-04 scheduler/filter+dates
- Шаг 1 с причинами (D1); целевые даты (D7, D2, А4 кир/лат); флаг просрочки.
GRAFIK-05 scheduler/owners
- Ключ владельца (ИНН цифры | норм. имя); физлицо по `Группа владельца`; правило ≤3 (A/Б); кластеры в окне,
  дата кластера = минимальная.
GRAFIK-06 scheduler/placement
- Локации (D8); длительность ceil(n/скорость) до 30 мин, мин 30, D3; день: старт, обед, переезд D4;
  сдвиг назад к ближайшему допустимому, иначе вперёд; просроченные — после регулярных в наименее загруженные месяцы.
GRAFIK-07 exporter.js — 4 листа по TZ §7 (+ примечание D5), автоширина, границы, формат дат/времени `с 9-00`.
GRAFIK-08 ui.js — настройки TZ §5 (+ адрес инспекции), drag-drop, 4 вкладки предпросмотра, скачивание, плашки ошибок/календаря.
GRAFIK-09 e2e + деплой — тест конвейера на фикстуре; `gh repo create Grafik_TO --public`, push, Pages через Actions,
  проверить что страница открывается и CORS isdayoff.ru (D10); README обновить.
