# Генератор графика технического осмотра

Статическое клиентское веб-приложение для формирования годового графика технического осмотра
самоходной техники по выгрузке из реестра (Excel). Работает полностью в браузере и подходит для
размещения на GitHub Pages.

## Онлайн-версия

Приложение опубликовано на GitHub Pages: <https://wwwmanager.github.io/Grafik_TO/>

## Использование

1. Перетащите выгрузку `.xlsx`/`.xls` в зону загрузки (или нажмите «Выбрать файл»).
2. Задайте параметры: целевой год, приёмные дни, отпуск инспектора, глубину давности ТО,
   окно группировки, режим для физлиц с ≤3 ед. и адрес инспекции, рабочий день и нагрузку.
3. Нажмите «Сформировать график» и проверьте вкладки «График ТО», «Детализация»,
   «Исключенные записи», «Сводка по месяцам».
4. Нажмите «Скачать Excel (.xlsx)» — файл формируется локально в браузере.

## Приватность (Zero Data Leakage)

- Файлы Excel содержат персональные данные и **никогда не покидают браузер**.
- Вся обработка, расчёты и анализ адресов выполняются на стороне клиента.
- Никакой сторонней аналитики, геокодирования и внешних скриптов/шрифтов.
- Единственный допустимый сетевой запрос — производственный календарь РФ по номеру года
  (`https://isdayoff.ru`), без пользовательских данных. Он ограничен директивой
  `Content-Security-Policy` в `index.html`.

## Разработка

```bash
npm install
npm run dev      # локальный сервер разработки
```

## Сборка и тесты

```bash
npm run build    # сборка в dist/
npm run test     # Vitest (один прогон)
npm run lint     # ESLint (flat config)
npm run verify   # lint + test + build
```

## Деплой

Пуш в ветку `main` запускает GitHub Actions (`.github/workflows/deploy.yml`): установка зависимостей
(`npm ci`), `npm run verify`, публикация `dist/` на GitHub Pages. В настройках репозитория источником
Pages должен быть выбран GitHub Actions. База сборки (`base: './'`) позволяет работать из любого
подкаталога репозитория.
